## 1. 5大画面テーマ設計（CSS変数による即時切替）

## 2. モバイルファーストの画面設計

1. **画面レイアウトのブレークポイント**:
   - `sm`: 640px
   - `md`: 768px
   - `lg`: 1024px（lg以上でPC用サイドバー固定表示、lg未満でスマホ用ヘッダー・ボトムナビ表示）
2. **親指リーチ（Thumb Zone）最適化**:
   - スマホ下部に主要5ナビゲーション（ダッシュボード、検索、記帳[中央強調]、口座、目標、設定）を配置。
3. **スマート入力フォーム**:
   - 数値入力（金額等）は `inputMode="numeric"` を設定し、スマホでテンキーを自動起動。
   - レスポンシブモーダル（スマホでは下部/中央にコンパクト表示、PCでは適切な幅でセンタリング）。

## 3. ゲーミフィケーションUI設計

1. **こまめ草生やし（Activity Bean Heatmap）**:
   - 直近4週間の日別記帳活動マトリックス（曜日 × 4週）。
   - 記帳件数に応じてマスの濃淡（0件: 白, 1件: 薄緑, 2件: 中緑, 3件以上: 濃緑）を表示。
2. **まめの樹（Bean Sprout）育成システム**:
   - 記録や貯蓄目標達成率に応じたステージ表示（種 → 双葉 → すくすく新芽 → 豊かな実り）。
3. **やさしいほめ言葉（ポジティブフィードバック）**:
   - 予算節約時や目標マイルストーン達成時に心温まるアドバイスを表示。
