## 2. モバイルファーストの画面設計

1. **画面レイアウトのブレークポイント**:
   - `sm`: 640px
   - `md`: 768px
   - `lg`: 1024px（lg以上でPC用サイドバー固定表示、lg未満でスマホ用ヘッダー・ボトムナビ表示）
2. **親指リーチ（Thumb Zone）最適化**:
   - スマホ下部に主要5ナビゲーション（ダッシュボード、検索、記帳[中央強調]、口座、目標、設定）を配置。
3. **スマート入力フォーム**:
   - 数値入力（金額等）は `inputMode="numeric"` を設定し、スマホでテンキーを自動起動。
   - レスポンシブモーダル（スマホでは下部/中央にコンパクト表示、PCでは適切な幅でセンタリング）。

## 3. ゲーミフィケーションUI設計

1. **こまめ草生やし（Activity Bean Heatmap）**:
   - 直近4週間の日別記帳活動マトリックス（曜日 × 4週）。
   - 記帳件数に応じてマスの濃淡（0件: 白, 1件: 薄緑, 2件: 中緑, 3件以上: 濃緑）を表示。
2. **まめの樹（Bean Sprout）育成システム**:
   - 記録や貯蓄目標達成率に応じたステージ表示（種 → 双葉 → すくすく新芽 → 豊かな実り）。
3. **やさしいほめ言葉（ポジティブフィードバック）**:
   - 予算節約時や目標マイルストーン達成時に心温まるアドバイスを表示。

## 4. 記帳タブ (`RegisterTab.tsx`) の3大入力モード

| モードID | 名称 | 想定ユースケース | 入力構成 |
| :--- | :--- | :--- | :--- |
| `single` | **1件ずつ登録** | 都度払いや日々のこまめな支出記録 | 日付、店舗名（履歴提案連動）、金額、費目、支払手段、メモ、貯蓄先口座（投資時） |
| `shop_batch` | **同店舗一括** | 1枚の店舗レシートの内訳登録（例: スーパーで食材と日用品を同時購入） | 日付（共通）、店舗名（共通）、支払手段（共通）、内訳明細行（費目・金額・メモ） × N行、合計金額 |
| `category_batch` | **同費目一括** | 週末等に同一費目（食費等）の複数レシートを一括記録 | 費目（固定）、支払手段（共通）、内訳明細行（日付・店舗名・金額・メモ） × N行、合計金額 |

### 一時保存（ドラフト）連携
- 手動保存 (`manualDraft`) / 自動保存 (`autoDraft`) ともに、モードごとの複数行構造（`batchRows`, `categoryBatchRows`）および合計件数・金額を完全に復元可能。

### 離脱時ガード（未保存警告: 要件 2-5）
- フォームに入力途中の値（金額・店舗名・メモ・一括行など）がある状態で、タブ切り替え（サイドバー・ボトムナビ等）やブラウザの閉じる/リロードを試みた場合、警告モーダル（`LeaveGuardModal.tsx`）またはブラウザ標準警告ダイアログ（`beforeunload`）を表示。
- 未入力時（`isFormDirty === false`）は確認ダイアログを表示せず即時遷移。
- 破棄確認時は自動退避ドラフト（`auto`）を削除し、指定先タブへ安全に遷移。
