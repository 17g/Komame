# 『Komame』詳細要件仕様書

## 1. ロール・権限構造

本システムはマルチテナント型家庭用家計簿であり、以下の3つのロールで構成される。

| ロール | 想定対象 | 主な利用可能機能 | 権限レベル |
| :--- | :--- | :--- | :--- |
| **最上位管理者 (Super Admin)** | システム運営者 | システム全体の稼働監視、世帯アカウントの発行/停止 | 全体 |
| **家庭管理者 (Household Admin)** | 世帯主・家計の主管理者 | 家族メンバーの招待・管理、パスワード要件設定、24時間チェックポイントリバート実行、家庭内全操作ログ閲覧・特定条件エクスポート、CSVフルインポート・エクスポート、全家計簿機能 | 世帯管理者 |
| **家庭メンバー (Household Member)** | 家族・パートナー | 1件/店舗一括/費目一括明細登録、一時保存（手動/自動）、ダッシュボード閲覧、口座残高・カード引き落とし予定確認、貯蓄目標進捗・草生やし、個別CSVエクスポート | 世帯一般 |

### 複数家庭所属への拡張性（先行N:M互換設計）
- 初期リリース時は「1ユーザー = 1世帯に所属」として運用。
- 内部データモデルは `users` - `household_memberships` - `households` の多対多構造（N:M）で構築されており、将来複数世帯の切り替え機能を追加する場合もDBスキーマ変更不要で移行可能。

## 2. 機能要件一覧

### 【要件 1】認証・セキュリティ・世帯サインアップ
- **1-1. ログイン/ログアウト**: メールアドレスとパスワードによる認証。
- **1-2. セルフサインアップ & 家族招待**:
  - 初回ユーザーはサインアップ時に「世帯名」を入力して新規登録（自動的に `Household Admin` に就任）。
  - 家族メンバーは管理者が発行した招待リンクまたはメールアドレス登録により世帯へ参加。
- **1-3. パスワードポリシー動的設定**:
  - 管理者画面で「最小文字数」「英大文字・小文字・数字・特殊文字の必須有無」を設定可能。
  - パスワードハッシュ化は `Argon2id` を採用。
- **1-4. セッション管理**: Secure / HttpOnly Cookie + JWT (HS256) によるセキュアな世帯コンテキスト伝播。

### 【要件 2 & 5】明細登録・資金移動・サジェスト
- **2-1. 1件ずつの明細登録**: 日付、金額、費目、支払手段、店舗・取引先名、簡易メモ、資金移動先口座（貯蓄・投資時）。
- **2-2. 同じ店舗に対する一括登録画面 (`shop_batch`)**: 1枚のレシートから複数行の品目・費目・金額を行追加して一括登録。
- **2-3. 同じ費目に対する一括登録画面 (`category_batch`)**: 同一費目（例: 食費）について複数店舗・日付・金額を連続登録。
- **2-4. タグ付け & カラーラベリング**: 支出や資金移動に色付きタグ（`#固定費`, `#自己投資`等）を付与。
- **2-5. 離脱時ガード（未保存警告）**: フォームに入力途中の値がある状態で画面遷移やタブ閉じを試みた場合、確認ダイアログを表示（未入力時は即時遷移）。
- **2-6. 簡易メモ機能**: レシート表記と実際の商品名の相違や個数を記録。
- **5. 機械的サジェスト機能**: 店舗名入力時に過去履歴から店舗名を補完し、決定時に最も使われた「費目」「支払元」を自動提案（1タップ適用）。

### 【要件 6】2段階の一時保存機能（明示的 & 自動保存）
- **6-1. 手動一時保存 (Manual Draft)**: 「一時保存」ボタン押下で保存（1件保持、上書き時は警告表示）。
- **6-2. 自動一時保存 (Auto Draft)**: キー入力停止後2秒（デバウンス）で自動退避。画面右下に控えめなトーストを表示。
- **6-3. 再開メニュー**: 登録画面トップに手動・自動保存日時・金額等を比較表示し、ワンタップで復元。
- **6-4. 警告表示**: 手動保存データがある状態で新規登録を完了しようとする場合、手動下書きデータが破棄される旨の警告確認モーダルを表示。

### 【要件 8, 9, 10, 11, 12, 18】口座・決済手段・資金フロー・色分け管理
- **8 & 10. 口座・カード・決済手段の登録**:
  - 銀行口座（普通・定期）、プリペイドウォレット（PayPay、Suica等）、クレジットカード、デビットカード、現金を登録。
  - クレジットカードには「締め日（1〜28日 / 99:月末）」、「引き落とし日（1〜28日 / 99:月末）」、「引き落とし月オフセット（0:当月 / 1:翌月 / 2:翌々月）」、「引き落とし元口座」を設定。
- **11. 残高管理 & 会計連動ロジック**:
  - 即時決済（現金、デビットカード、QR残高払い）: 登録と同時に該当口座・ウォレット残高が即時減額。
  - クレジットカード払い: 登録時点では銀行口座残高は減少しない（未精算として引き落とし予定日に計上）。
  - 口座間振替（transfer）: 出金元口座を減額し、入金先口座を加算。
  - 貯蓄・投資（NISA・定期預金）支出: 出金元口座を減額し、指定された投資先口座へ同額加算（受入明細を自動生成）。
- **9. クレジットカード引き落とし予定額・原資チェック**:
  - 次回引き落とし予定額を集計し、紐づく銀行口座の現在残高と比較して「原資充足」または「不足（あと〇〇円不足）」を警告。
- **12. 資金フローの可視化**: 口座引き落とし、窓口引き出し、カード決済、チャージ、投資振替を一元追跡。
- **18. 口座内での疑似的な資金色分け（バーチャル貯蓄・取り分け）**:
  - 口座残高の一部を特定用途（車検用・生活防衛資金等）としてバーチャルにロック。
  - 「実質利用可能残高 = 現在残高 - ロック金額合計」を算出・表示。

### 【要件 4】費目管理（マスターID管理 & 初期プリセット）
- 費目は内部IDで管理。階層構造（大分類/中分類）に対応。
- 費目名やアイコン・カラーを変更しても過去の全明細が即座に連動反映。
- 新規世帯開設時に日本の標準家計簿プリセット（食費、外食、日用品、住居費等12種）を自動シード投入。

### 【要件 7】データインポート・エクスポート (CSV)
- **文字コード**: 日本のExcelで文字化けしない **UTF-8 (BOM付き)**。
- **エクスポート**: 全明細CSVおよび口座一覧CSV出力。フルエクスポートは管理者権限限定。
- **インポート**: 家計簿明細CSVの取り込み（カラムマッピング、同一日・店舗・金額の重複候補警告）。管理者限定。

### 【要件 14, 15, 17, 17-2】ダッシュボード・統計・目標・検索
- **14. ダッシュボード**: 総資産、実質利用可能残高、貯蓄ロック額、次回クレカ引き落としアラート、費目別比率バー、最近の明細。
- **15. 単純検索**: 収支種別（全明細 / 支出のみ / 収入のみ / 資金移動のみ）、費目、決済手段、期間、キーワードによる絞り込み。実質収入・実質支出・純貯蓄のスマート集計。
- **17. 収入登録**: 額面給与、税金・社保控除額、手取り入金先口座、臨時収入フラグ。
- **17-2. 貯蓄目標管理**: 複数貯蓄口座を合算/単独で目標額に対する達成率（%）と残り金額の可視化。

### 【要件 16】ゲーミフィケーション・モチベーション向上
- **こまめ草生やし（Activity Bean Heatmap）**: 記帳した日の濃淡マトリックスとストリーク日数表示。
- **まめの樹（Bean Sprout）育成**: 記録や貯蓄目標達成に応じた新芽の成長インタラクション。
- **やさしいほめ言葉・アドバイス**: 予算達成時や節約時の前向きなメッセージ。

### 【要件 3, 21, 22】管理者機能・操作ログ・24時間チェックポイントリバート
- **3-1 & 21. 操作ログ**: いつ・誰が・どの画面で何のデータを登録/更新/削除したかを記録。
- **3-2. ユーザー管理**: 家族メンバーの招待、権限変更、パスワードリセット、無効化。
- **3-3. 条件付きログエクスポート**: ユーザー・期間・操作種別を指定してCSV/JSON出力。
- **3-4. システム設定**: 通貨表示（¥ / $ / €）、日付フォーマット、パスワード強度ポリシー。
- **22. 24時間チェックポイントリバート**:
  - トランザクションごとにチェックポイントを作成（有効期限24時間）。
  - 指定時点以降の明細データおよび連動した口座残高を該当状態にロールバック。
  - **一時保存データのリセット**: リバート実行時、`drafts` テーブルを物理削除して空に初期化。
  - **家族影響警告**: 同一世帯の他メンバーが登録した明細への影響サマリーを表示し、7文字のランダム確認コード入力による二重確認を必須化。

### 【要件 13, 19, 20, 23】UI/UX・テーマ・通知
- **13. レスポンシブ**: スマホ最優先（モバイルファースト）。片手操作ボトムナビ、テンキー自動起動（`inputMode="numeric"`）。
- **19. 項目ヘルプ**: 各入力項目の「？」アイコンでポップアップ解説。
- **20. テーマ切替**: 5種類のカラーテーマを即時切替。
- **23. アプリ内通知ボックス**: 引き落としアラート、資金不足サジェスト、目標マイルストーンを表示。

## 3. データ削除ポリシー

| 対象データ | 削除方式 | 具体的挙動 |
| :--- | :---: | :--- |
| **費目マスター (`categories`)** | **論理削除 (アーカイブ)** | `is_archived = true` となり新規選択肢から非表示。過去明細やグラフは維持。 |
| **口座・決済手段 (`accounts`, `payment_methods`)** | **論理削除 (非活性化)** | `is_active = false` となり新規選択肢から非表示。過去の決済履歴は維持。 |
| **家族ユーザー (`household_memberships`)** | **論理削除 (無効化)** | ステータスを `inactive` にしてログイン遮断。過去の登録履歴は記録保持。 |
| **支出・収入明細 (`transactions`)** | **論理削除 / ログ退避** | 画面・残高から即時除外。`audit_logs` に退避され、24hリバート時はログから復元可能。 |
| **一時保存データ (`drafts`)** | **物理削除** | 一時作業データのため、破棄・上書き・リバート時はDBから物理削除。 |
| **家庭アカウント全体の退会** | **物理完全抹消** | 個人情報保護のため、該当世帯スキーマ（`DROP SCHEMA tenant_xxx CASCADE`）を物理完全抹消。 |
